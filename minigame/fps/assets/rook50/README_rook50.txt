ROOK .50 — 테스트용 FPS 게임 에셋

파일
- rook50_game_asset.glb : 권장. 머티리얼과 분리된 파츠가 포함된 glTF Binary.
- rook50_game_asset.obj / material_0.mtl 등 : 범용 OBJ 버전.
- rook50_game_asset.stl : 재질 없는 단일 메시 백업.
- rook50_preview.png : 자동 생성 미리보기.

스케일/축
- 전체 길이 약 0.29 m
- X축: 총구 방향, Y축: 좌우, Z축: 위
- 원점은 모델 중앙 부근

주의
- 한 장의 측면 참고 이미지를 바탕으로 만든 테스트용 저~중폴리 모델입니다.
- 실제 기계 구조를 재현한 모델이 아니라 게임용 비기능성 외형 에셋입니다.
- 실제 프로젝트에서는 UV 언랩, 베이크, LOD, 충돌 메시, 애니메이션용 피벗을 추가하는 편이 좋습니다.
