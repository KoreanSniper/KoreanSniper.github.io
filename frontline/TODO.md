## 온라인 기능 범위

현재 Firebase는 방 생성·코드 참가·실시간 대기실·호스트 시작 신호까지 담당한다. 실제 전투 상태는 아직 각 브라우저에서 동기화되지 않으므로, 온라인 UI를 완전한 멀티플레이로 표시하지 않는다.

## 지형 변경 금지 사항

- 현재 고도 팔레트, 표면 질감, 방향성 hillshade, 모래 해안은 임의로 변경하지 않는다.
- hillshade 입력 높이는 연속 실수값을 유지하고 `round`, `floor`, 단계형 치환을 적용하지 않는다.
- 최고 고도를 단순 clamp해서 넓은 평평한 정상을 만들지 않는다.
- 성능 문제를 해결하기 위해 전체 해상도 계산을 매 프레임 반복하지 않는다.
